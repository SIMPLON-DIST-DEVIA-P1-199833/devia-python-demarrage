## Exercice : calcul de panier
Exercice de premiers pas de calcul conditionnel avec boucles en Python

## Installation
Aucunes dépendences.
Travail sur Python 3.

## Lancement
```sh
python3 commande.py
```

### Structure de code
Un `main()` en bas du fichier commande lance les tests associés (basés sur des `assert`) pour les chapitres `1. Variables et affichage`, `2. Conditions` et `3. Boucles` du travail demandé.

Un choix a été fait de ne pas utiliser [unittest](https://docs.python.org/3/library/unittest.html), [pytest](https://docs.pytest.org/en/stable/) ou d'autres bibliothèques de test, ni de travailler sur plusieurs fichiers.
